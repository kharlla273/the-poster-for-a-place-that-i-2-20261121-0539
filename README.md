**AERTHYS — The Floating Isles.** A travel poster for a place that does not exist, drawn entirely in code. `main.ts` (Node 22, stdlib only, no network, no assets) renders a sunset sky over a sea of clouds, a striped lighthouse on a floating island, a waterfall spilling off its edge, a drifting hot-air balloon — and the invented place's name, AERTHYS, set large across the sky with the tagline "WHERE THE SUN SETS LAST". It writes one deterministic, byte-identical image to `/output/entry.png` on every run: 1024×1024 PNG, well under the 1 MiB cap.

## Run it

```sh
node main.ts
```

`MAKEFUN_OUTPUT_DIR` overrides the output directory (default `/output`). On Node 22.6–22.17 run it as `node --experimental-strip-types main.ts`; Node 22.18+ runs the TypeScript directly.
